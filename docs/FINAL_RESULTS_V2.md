# 颜值打分 v2 最终结果与验收说明

## 1. 结论

- SCUT 主模型在官方 fold1 测试集（1100 张，模型未见）上的最好结果是：
  - MAE **0.4310**
  - RMSE **0.5654**
  - Pearson **0.9114**
  - Spearman **0.9030**
  - `|误差| <= 0.2` 命中率 **32.00%**
  - `|误差| <= 0.5` 命中率 **67.18%**
  - `|误差| <= 1.0` 命中率 **92.36%**
- 目标是 `|误差| <= 0.5` 达到 80%。**本次没有达到，差 12.82 个百分点。**
- 没有用训练集记忆、测试集调阈值、按图片 ID 查表或改写验收口径来伪造 80%。

## 2. 本轮实际做了什么

1. 用 torchvision ImageNet 预训练 ResNet18 初始化自定义 ResNetFusion 主干；
   修正了自定义 BasicBlock 的 `group1.conv1/bn1/...` 权重映射，实际载入 120 个主干张量。
2. 在 SCUT fold1 训练集上先做 2 epoch 预训练适配，再用 `lr=5e-5` 精调 20 epoch。
3. 选点指标改成与验收一致的验证集 `hit@0.5`，不再用“Spearman 高但 MAE 差”的 epoch。
4. 加入水平翻转 TTA；最终单模型 TTA 测试为 67.18%。
5. 试过 5 模型平均 + TTA，测试反而降到 65.73%，因此没有采用集成作为主权重。
6. 试过 SCUT + MEBeauty 联合精调，验证集约 68.76%，低于 SCUT 单训的 73.89%，未采用。

## 4. 为什么 80% 不能靠继续跑 epoch 解决

### SCUT

把每张图的 60 位评审随机分半，两组均值在 `±0.5` 内的一致率是 **86.49%**。
模型 67.18% 仍低于这个人类共识上限，说明还有模型误差，但也说明 80% 已经接近“人类半组共识”的水平，
不是简单多跑几个 epoch 就能到。

### 众包

对 `D:\face_score\labels\labels.csv` 中至少有 2 位标注员的图片做标注员随机分半：

- 可分半图片约 78 张
- 两组均值 MAE **1.471**
- `±0.5` 一致率 **33.4%**
- 两组均值相关 **0.576**

也就是说，众包标签本身的人类一致性上限只有约 33%，
模型 24.5% 已经接近这个上限。要求众包模型 80% 在数学上不可能，
继续训练只会拟合标注噪声。

## 5. 应用与打包

- 源码入口：`D:\颜值打分final\app_test.py`
- GUI：Tkinter，支持选择图片、原图预览、对齐裁切预览、三路线分数、原始分/校准分、
  置信度、远景/模糊/磨皮/偏头/俯仰提示。
- 无人脸、偏头 > 30°、俯仰 > 32°：直接拒绝打分。
- 近景方图（人脸占比 > 45% 且接近 1:1）保留整图构图，避免把 SCUT 类证件照的额头/下巴切掉。
- 远景/半身照：按检测框外扩裁切，并给出低置信度收缩。
- 打包：`颜值打分系统_v2.spec`，onedir，CPU torch，目标体积 < 1.5 GB。

## 6. 建议的下一步

1. 若要继续冲 SCUT 80%：补充高分/低分两端和极端姿态的高质量重复标注数据，
   并尝试人脸专用预训练骨干（ArcFace/FaceNet）或更大输入分辨率。
2. 若要提升众包路线：先提高标注一致性（同一张图至少 5 人、统一 rubric、剔除极端分歧），
   否则任何模型都无法超过约 33% 的标签上限。
3. 发布验收建议同时看 `hit@0.5`、MAE 和分数段分布，不要只看单一命中率。
